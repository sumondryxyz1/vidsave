# DownLoadr — ভিডিও ও অডিও ডাউনলোডার

দুইভাবে ব্যবহার করা যায়:

1. **ওয়েব অ্যাপ** — ব্রাউজারে লিংক পেস্ট করুন, কোয়ালিটি বেছে সরাসরি ডাউনলোড
2. **টেলিগ্রাম বট** — বটকে লিংক পাঠালে ফাইল ফেরত পাঠায়

দুটোই [yt-dlp](https://github.com/yt-dlp/yt-dlp) ইঞ্জিন ব্যবহার করে, তাই ১০০০+ সাইট
(YouTube, Facebook, Instagram, TikTok, X/Twitter, Vimeo, Reddit, প্রভৃতি) সাপোর্টেড।

## ফিচার

- 🔗 যেকোনো লিংক পেস্ট করলেই মেটাডেটা (টাইটেল, থাম্বনেইল, ডিউরেশন) দেখায়
- 🎬 2160p / 1440p / 1080p / 720p / 480p / 360p — যেটা সোর্সে আছে
- 🎵 MP3 অডিও এক্সট্রাকশন, **বিটরেট বাছাই** (128 / 192 / 320 kbps)
- 🎞️ **প্লেলিস্ট ও চ্যানেল** — এন্ট্রি বেছে নিন বা পুরোটা ZIP করে নামান
- 💬 **সাবটাইটেল এম্বেড** (ভিডিওতে সাবটাইটেল যোগ করে)
- 📊 লাইভ প্রোগ্রেস বার + আইটেম কাউন্ট (ওয়েবে SSE, টেলিগ্রামে মেসেজ এডিট)
- ⏹️ **জব ক্যানসেল** (ওয়েবে চলমান ডাউনলোড থামানো যায়)
- 🌐 **প্রক্সি সাপোর্ট** — 403 ব্লক বা জিও-রেস্ট্রিকশন সামলাতে
- 🔒 প্রাইভেট/এজ-রেস্ট্রিক্টেড কনটেন্টের জন্য কুকি সাপোর্ট
- ⚡ একসাথে কয়েকটা ডাউনলোড (concurrency limit সহ)
- 📲 **মোবাইল অ্যাপ (PWA)** — ফোনে হোম স্ক্রিনে ইনস্টল করা যায়

## সেটআপ

```bash
pip install -r requirements.txt
```

ffmpeg/ffprobe আসে `static-ffmpeg` প্যাকেজের সাথে — প্রথমবার চালালে বাইনারি
ডাউনলোড হয়ে যাবে।

### ওয়েব অ্যাপ চালানো

```bash
python webapp.py          # ডিফল্ট পোর্ট 12000
PORT=8000 python webapp.py
```

তারপর ব্রাউজারে খুলুন `http://localhost:12000`।

### টেলিগ্রাম বট চালানো

```bash
export BOT_TOKEN="123456:ABC-তোমার-টোকেন"   # BotFather থেকে
python bot.py
```

## কুকি (ঐচ্ছিক)

প্রাইভেট ভিডিও, এজ-ভেরিফাইড বা লগইন-দরকার কনটেন্টের জন্য ব্রাউজার থেকে
Netscape ফরম্যাটে `cookies.txt` এক্সপোর্ট করে পাথ দিন:

```bash
export YT_COOKIES=/path/to/youtube-cookies.txt
export FB_COOKIES=/path/to/facebook-cookies.txt
export IG_COOKIES=/path/to/instagram-cookies.txt
```

## এনভায়রনমেন্ট ভেরিয়েবল

| ভেরিয়েবল | ডিফল্ট | কাজ |
|---|---|---|
| `BOT_TOKEN` | — | টেলিগ্রাম বট টোকেন (শুধু `bot.py`) |
| `PORT` | `12000` | ওয়েব সার্ভারের পোর্ট |
| `MAX_UPLOAD_MB` | `50` | টেলিগ্রাম আপলোড লিমিট (লোকাল Bot API হলে বাড়ান) |
| `DOWNLOAD_TIMEOUT` | `1800` | প্রতি ডাউনলোডের সর্বোচ্চ সময় (সেকেন্ড) |
| `MAX_CONCURRENT` | `3` | একসাথে সর্বোচ্চ ডাউনলোড |
| `JOB_TTL` | `3600` | ওয়েবে ফাইল কতক্ষণ রাখা হবে (সেকেন্ড) |
| `PROXY` | — | প্রক্সি URL, যেমন `http://user:pass@host:port` |
| `YT_COOKIES` / `FB_COOKIES` / `IG_COOKIES` | — | কুকি ফাইলের পাথ |

## API (ওয়েব)

| মেথড | পাথ | কাজ |
|---|---|---|
| `POST` | `/api/probe` | `{url}` → টাইটেল, থাম্বনেইল, উপলব্ধ কোয়ালিটি, প্লেলিস্ট কিনা |
| `POST` | `/api/download` | `{url, quality, audio_bitrate, subtitles, playlist}` → `{job_id}` |
| `POST` | `/api/cancel/{job_id}` | চলমান জব বাতিল |
| `GET` | `/api/progress/{job_id}` | SSE স্ট্রিম — লাইভ প্রোগ্রেস |
| `GET` | `/api/file/{job_id}` | রেডি ফাইল (প্লেলিস্ট হলে ZIP) ডাউনলোড |

## সীমাবদ্ধতা

- **টেলিগ্রামে ৫০MB আপলোড লিমিট**; ওয়েবে এমন সীমা নেই (ব্রাউজারে সরাসরি নামে)।
  টেলিগ্রামে বড় ফাইল পাঠাতে [লোকাল Bot API সার্ভার](https://github.com/tdlib/telegram-bot-api)
  চালিয়ে `MAX_UPLOAD_MB` বাড়ান (সর্বোচ্চ 2000MB)।
- ডেটাসেন্টার IP থেকে YouTube কখনো `403` দিতে পারে। কুকি দিলে বা রেসিডেন্সিয়াল
  প্রক্সি হলে ঠিক হয়। ডাউনলোডার-ফ্রেন্ডলি হোস্টে চালানো বাঞ্ছনীয়।
- শুধু নিজের বা অনুমোদিত কনটেন্ট ডাউনলোড করুন; সাইটের শর্তাবলি মেনে চলুন।
